## Objetivo

A segunda atividade teve como objetivo aplicar na prática os conceitos iniciais de controle de versão utilizando **Git e GitHub**.

Para isso, foi utilizado um projeto web composto por HTML, CSS e JavaScript, permitindo acompanhar o processo desde a criação dos arquivos até o registro e publicação de diferentes versões do projeto.

---

## Proposta da atividade

Foram solicitadas as seguintes etapas:

1. instalar o Visual Studio Code;
2. criar os arquivos:
   - `index.html`;
   - `style.css`;
   - `script.js`;
3. inserir os códigos fornecidos para cada arquivo;
4. manter todos os arquivos dentro da mesma pasta;
5. configurar o Git no ambiente de desenvolvimento;
6. integrar o projeto a um repositório no GitHub;
7. inicializar o controle de versão;
8. realizar a publicação inicial do projeto;
9. modificar o código;
10. registrar as alterações utilizando commits;
11. identificar novas versões utilizando tags;
12. documentar as etapas realizadas.

---

## Tecnologias utilizadas

Durante a atividade foram utilizadas as seguintes ferramentas:
