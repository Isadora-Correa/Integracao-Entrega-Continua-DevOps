## 🎯 Objetivo

Aplicar, na prática, os conceitos iniciais de controle de versão utilizando **Git e GitHub**.

Para isso, foi utilizado um projeto web composto por HTML, CSS e JavaScript, permitindo acompanhar todo o processo: da criação dos arquivos ao registro e à publicação de diferentes versões do projeto.

## 📋 Proposta da atividade

1. Instalar o Visual Studio Code.
2. Criar os arquivos `index.html`, `style.css` e `script.js`.
3. Inserir os códigos fornecidos em cada arquivo.
4. Manter todos os arquivos na mesma pasta.
5. Configurar o Git no ambiente de desenvolvimento.
6. Integrar o projeto a um repositório no GitHub.
7. Inicializar o controle de versão.
8. Realizar a publicação inicial do projeto.
9. Modificar o código e registrar as alterações com commits.
10. Identificar novas versões utilizando tags.
11. Documentar as etapas realizadas.

## 🧰 Tecnologias utilizadas

- Visual Studio Code;
- Git e GitHub;
- HTML;
- CSS;
- JavaScript.

## 🗂️ Estrutura do projeto

```text
Projeto/
├── index.html
├── style.css
└── script.js
```

## 🛠️ Desenvolvimento

Os arquivos da aplicação foram criados e organizados em uma única pasta. Depois, o Git foi configurado para acompanhar as alterações do projeto e registrar sua evolução por meio de commits e tags.

O repositório local foi conectado ao GitHub, tornando possível armazenar o histórico remotamente e compartilhar o trabalho do grupo. Por fim, a aplicação foi publicada na Vercel para que pudesse ser acessada pela internet.

## ✅ Resultado

A atividade permitiu compreender o fluxo básico de versionamento: criar ou alterar arquivos, preparar as mudanças, gerar commits, marcar versões e enviá-las a um repositório remoto. A aplicação também foi disponibilizada publicamente.
