# Integração e Entrega Contínua — DevOps

Repositório destinado à organização dos conteúdos e atividades desenvolvidos durante a disciplina de **Integração e Entrega Contínua (DevOps)**.

A proposta deste repositório é centralizar os materiais utilizados ao longo do semestre, mantendo cada aula organizada individualmente e facilitando o acesso aos slides, atividades, referências e projetos desenvolvidos.

> Os projetos maiores possuem seus próprios repositórios. Neste repositório são mantidos apenas os materiais da disciplina e a documentação das atividades, com os respectivos links para os projetos quando necessário.
